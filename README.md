# QA-AI-Agent-Lab-Automation

Proyecto de laboratorio para automatización de pruebas utilizando Inteligencia Artificial, APIs y herramientas QA.

## Objetivo

Explorar la integración de agentes IA aplicados al proceso de Quality Assurance:

- Generación automática de casos de prueba.
- Creación de escenarios Gherkin.
- Análisis de riesgos.
- Generación de pruebas automatizadas.
- Ejecución de pruebas API.

## AgentesIA

Módulo experimental de agentes inteligentes orientados a tareas QA.

Incluye:

- Generación de casos de prueba.
- Clasificación de escenarios.
- Creación de criterios de aceptación.
- Generación de pruebas automatizadas.

## BancoQA_API

API simulada de un sistema bancario para pruebas.

Incluye endpoints relacionados con:

- Clientes
- Cuentas
- Tarjetas
- Movimientos
- Pagos
- Financiaciones
